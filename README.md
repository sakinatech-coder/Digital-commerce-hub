# Digital Commerce Hub

A digital marketing learning website for B.Com students. It explains key digital marketing topics, suggests beginner projects, lists career options and includes a short quiz.

## Live Demo
https://sakinatech-coder.github.io/Digital-commerce-hub/

## Features
- Home page with a clear introduction to the platform
- Learn section with 6 topics: SEO, Social Media Marketing, Content Marketing, Email Marketing, Google Ads & Analytics, Affiliate Marketing
- Links to free learning resources for each topic
- 3 beginner-friendly project ideas (social media campaign, SEO content plan, business marketing plan)
- Career section with 6 entry-level roles after B.Com
- Digital marketing quiz with 5 questions and a score check
- Contact form that prepares an email

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository
2. Open `index.html` in your browser
